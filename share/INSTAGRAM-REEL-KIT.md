# Reel and sharing kit

## What to give viewers

Share `github-profile-starter.zip` together with `GitHub-Profile-Guide.pdf` or the Markdown guide. The ZIP includes `START-HERE.md`, an editable configuration file, a build script and generic artwork. It does not include your portrait or personal project claims.

Before posting, publish these three files somewhere viewers can download them:

- `share/github-profile-starter.zip`
- `share/GitHub-Profile-Guide.pdf`
- `share/GITHUB-PROFILE-GUIDE.md`

One option is your GitHub repository: upload the `share` folder along with your other changes. Open each file on GitHub, copy its actual page or download link, and use those verified links in your bio or reply. The local computer paths are not public download links. For the ZIP, viewers should select the download button.

Keep the starter as a separate download so viewers do not have to clone your personal profile or reuse your photo. Test the links in a signed-out browser before publishing the reel.

## Reel script: about 35–45 seconds

**0–5 seconds — Show the finished profile**

“Want a GitHub profile like this? Here’s a template you can make your own.”

On screen: **Upgrade your GitHub profile**

**5–12 seconds — Show the starter folder**

“Download the starter, extract it, and open the configuration file.”

On screen: **Download → Extract → Open profile.config.json**

**12–22 seconds — Show the edits**

“Add your name, GitHub username, skills, projects and your own photo.”

On screen: **Your details. Your projects. Your photo.**

**22–29 seconds — Show the terminal**

“With Node.js installed, run this command to build your profile graphics.”

On screen: **node scripts/build-profile.cjs**

**29–37 seconds — Show GitHub**

“Upload the files to a public repository named exactly the same as your GitHub username.”

On screen: **username/username → Public → README.md at root**

**37–45 seconds — Show the result**

“The starter and step-by-step guide are in the link in my bio. Save this for your next profile update.”

On screen: **Starter + guide → Link in bio**

Use the “link in bio” line only after adding a working download link. If you prefer comment requests, use the alternative caption below and send the files yourself.

## Creator checks before posting

- Download your own shared ZIP into a new folder and follow the guide once.
- Use an account's real username when checking the profile-repository rule.
- Check desktop and mobile artwork after personalizing.
- Confirm the ZIP and guide links work while signed out.
- Make the Node.js build step visible; viewers cannot personalize the SVG text by changing only their GitHub username.
- If you update the template, rebuild the ZIP with `node scripts/package-starter.cjs` and create the archive again from the staged folder.
